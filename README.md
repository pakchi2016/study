### 【問題】

次の (1) 〜 (20) のうち、**$y$ が $x$ の関数であるものには「○」**、**関数でないものには「×」** を（ ）に書きなさい。
（※判断のポイント：$x$ の値を1つ決めると、$y$ の値が**ただ1つ**に決まるかどうかを考えよう！）

**(1)** 1個 $80$ 円の消しゴムを $x$ 個買ったときの代金 $y$ 円 …………………………（  ）

**(2)** 年齢が $x$ 歳の人の身長 $y\text{ cm}$ ……………………………………………………（  ）

**(3)** $500\text{ mL}$ 入りのペットボトルのお茶を $x\text{ mL}$ 飲んだときの残りの量 $y\text{ mL}$ …（  ）

**(4)** 面積が $36\text{ cm}^2$ である長方形の、縦の長さ $x\text{ cm}$ と横の長さ $y\text{ cm}$ …………（  ）

**(5)** 周の長さが $16\text{ cm}$ である長方形の、縦の長さ $x\text{ cm}$ と面積 $y\text{ cm}^2$ …………（  ）

**(6)** 周の長さが $24\text{ cm}$ である二等辺三角形の、底辺の長さ $x\text{ cm}$ と面積 $y\text{ cm}^2$（  ）

**(7)** 面積が $20\text{ cm}^2$ である三角形の、底辺の長さ $x\text{ cm}$ と高さ $y\text{ cm}$ ……………（  ）

**(8)** 面積が $30\text{ cm}^2$ である三角形の、底辺の長さ $x\text{ cm}$ と周の長さ $y\text{ cm}$ ………（  ）

**(9)** 時速 $4\text{ km}$ で $x$ 時間歩いたときに進んだ道のり $y\text{ km}$ …………………………（  ）

**(10)** $12\text{ km}$ の道のりを時速 $x\text{ km}$ で走ったときにかかる時間 $y$ 時間 ……………（  ）

**(11)** 1日のうちの昼の長さ $x$ 時間と、夜の長さ $y$ 時間 ……………………………（  ）

**(12)** テストで $x$ 時間勉強した人の得点 $y$ 点 …………………………………………（  ）

**(13)** 1辺の長さが $x\text{ cm}$ である正方形の周の長さ $y\text{ cm}$ ……………………………（  ）

**(14)** 半径が $x\text{ cm}$ である円の面積 $y\text{ cm}^2$ （円周率は $\pi$ とする） ………………（  ）

**(15)** 重さが $x\text{ g}$ の郵便物を送るときの送料 $y$ 円 ……………………………………（  ）

**(16)** 送料が $x$ 円の郵便物の重さ $y\text{ g}$ …………………………………………………（  ）

**(17)** 1本 $100$ 円のペンを $x$ 本買い、$1000$ 円札を出したときのおつり $y$ 円 ……（  ）

**(18)** $6\text{ L}$ のジュースを $x$ 人で等分したときの、1人分の量 $y\text{ L}$ …………………（  ）

**(19)** 出席番号が $x$ 番の生徒の誕生月 $y$ 月 ……………………………………………（  ）

**(20)** 出席番号が $x$ 番の生徒の足のサイズ $y\text{ cm}$ （特定の1クラスとする） ……（  ）

# 【解答・解説編】

| 番号 | 答え | 解説・理由（かっこ内は表せる場合の式） |
| --- | --- | --- |
| **(1)** | **○** | $x$ が決まれば代金は1つに決まる。（比例：$y = 80x$） |
| **(2)** | **×** | 同じ年齢でも人によって身長はバラバラなので、1つに決まらない。 |
| **(3)** | **○** | 飲んだ量が決まれば残りも1つに決まる。（$y = 500 - x$） |
| **(4)** | **○** | 縦が決まれば横も1つに決まる。（反比例：$y = \frac{36}{x}$） |
| **(5)** | **○** | 縦が $x$ なら横は $(8 - x)$ になり、面積も1つに決まる。（$y = x(8 - x)$） |
| **(6)** | **○** | 底辺が $x$ なら残りの2辺も1つに決まり、形が確定するため面積も1つに決まる。 |
| **(7)** | **○** | 底辺×高さ÷2＝20 より、底辺が決まれば高さも1つに決まる。（反比例：$y = \frac{40}{x}$） |
| **(8)** | **×** | 【ひっかけ】底辺と面積が決まっても、三角形の「傾き具合（形）」が1つに決まらないため、周りの長さは1つに定まらない。 |
| **(9)** | **○** | 歩いた時間が決まれば道のりも1つに決まる。（比例：$y = 4x$） |
| **(10)** | **○** | 速さが決まれば時間も1つに決まる。（反比例：$y = \frac{12}{x}$） |
| **(11)** | **○** | 1日は24時間なので、昼の長さが決まれば夜の長さも1つに決まる。（$y = 24 - x$） |
| **(12)** | **×** | 同じ時間だけ勉強しても、人によって点数は違うため1つに決まらない。 |
| **(13)** | **○** | 1辺が決まれば周の長さも1つに決まる。（比例：$y = 4x$） |
| **(14)** | **○** | 半径が決まれば円の面積も1つに決まる。（$y = \pi x^2$ ※式は中3範囲だが関数である） |
| **(15)** | **○** | 【超重要】重さが決まれば、料金表によって送料は必ず1つに決まる。（式には表せないが関数である） |
| **(16)** | **×** | 【超重要】(15)の逆。例えば送料が110円と決まっても、重さが20gか30gかは1つに決まらない。 |
| **(17)** | **○** | 本数が決まればおつりも1つに決まる。（$y = 1000 - 100x$） |
| **(18)** | **○** | 人数が決まれば1人分の量も1つに決まる。（反比例：$y = \frac{6}{x}$） |
| **(19)** | **○** | 特定のクラスであれば、出席番号を1つ決めればその生徒は1人に決まり、誕生月も必ず1つに決まる。 |
| **(20)** | **○** | (19)と同じく、出席番号が決まれば生徒が1人に定まるため、その時点の足のサイズも1つに決まる。（※もし「身長 $x\text{ cm}$ の人の足のサイズ $y\text{ cm}$」なら同じ身長で複数の人がいるため **×** になる） |
